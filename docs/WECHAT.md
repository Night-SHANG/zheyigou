# 《这一钩捞什么》微信小游戏试玩工程

本包是离线单机玩法试玩，不接登录、广告、支付、排行榜、云存档或第三方服务。使用共享 CommonJS 玩法和 Canvas 2D 渲染，微信入口有独立触摸、生命周期、图片、存储适配。不是浏览器页面套壳。

## 构建与导入

1. 开发源码根目录执行 `npm run build`。构建器生成 `wechat/app.js` 并复制实际运行资源。
2. 在微信开发者工具中导入最终的 `wechat` 文件夹。选择小游戏项目。
3. `project.config.json` 的 `appid` 刻意留空。请在工具中填入你拥有的小游戏 AppID；不要直接使用别人的ID或将空字段当成有效ID。不同工具版本的无AppID/测试项目能力需以工具实际界面为准，本包不承诺匿名真机预览。
4. 编译后应出现主菜单，按界面按钮开始。在非按钮区域按下并拖动控制方向，右侧操作键在靠近物品、网或码头时执行交互。抬手/取消立即停止。
5. 切后台取消触点并暂停，回到前台由玩家明确继续。不要把后台时间当作游戏消耗。

若暂时没有小游戏AppID，浏览器包可独立验证玩法；源码和离线微信工程仍保留，不需要为此创建账号、凭据或修改安全设置。

## 工程边界

- game.js：真实微信入口；注入小游戏全局 requestAnimationFrame / cancelAnimationFrame。
- platform.js：wx.createImage、wx触摸、wx生命周期、wx存储薄适配。没有 document/window/HTMLAudio。
- app.js：构建生成的完整游戏代码，不要在微信工具里手动改此生成文件。
- game.json：竖屏基础配置。
- assets/：本地资源，无CDN依赖。
- project.config.json：小游戏项目与根路径配置，未包含账号密钥。

逻辑宽390，逻辑高度按窗口比例计算；Canvas物理尺寸按设备DPR（最高3）计算。绘制与触摸使用同一逻辑坐标。主包建议保留在4MiB以内并留余量，这是保守项目预算，不等于本轮已核验平台最新实际上传限额。

## 验证口径

`npm test` 包含微信薄适配契约。正式bundle宿主测试使用真实构建入口和游戏逻辑，模拟微信事件与绘图接口；它检查入口连接、触摸状态转换与绘制调用，但不能证明真实微信渲染、系统字体、设备音频、GPU或触摸手感。实际微信IDE、真机预览/安装与平台上传必须分别记录，不从浏览器通过外推。

本轮不运行 miniprogram-ci 预览/上传，不申请私钥、不配置IP白名单、不提交审核，也不使用用户电脑。官方CI接收完整小游戏工程且预览/上传需要额外账号条件，不是无凭据的小游戏模拟器。

包含已授权CC0短音效ui-click、pickup、net-cut；微信使用按需创建的InnerAudioContext，每种最多一声部，总上限3。默认开启，可静音；后台停止；异常不阻断游戏。无BGM。真实微信听感仍未验。
