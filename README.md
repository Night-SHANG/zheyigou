# 这一钩，捞什么？

3 关竖屏海底打捞玩法实验，浏览器和微信小游戏共用纯 JavaScript 玩法与 Canvas 2D 渲染。

## 浏览器试玩

Windows 可双击 `START-WINDOWS.bat` 自动打开浏览器（优先使用已安装的 Python 3，没有 Python 时直接打开页面）。也可直接打开 `index.html`，或在本目录运行 `python -m http.server 8080` 后打开 `http://localhost:8080`。发布前不需要服务器接口、账号或付费服务。

拖动空白区域移动，松手停住。靠近物品点抓取；回到水面后点交付收获。键盘也支持 WASD / 方向键、空格抓取、P 暂停。首页右上可静音。

## 微信小游戏

导入 `wechat/` 到微信开发者工具，并填写自己的小游戏 AppID。具体步骤与验收边界见 `docs/WECHAT.md`。这是一份开发工程，不是已经发布或完成真机验收的微信小游戏。

## 三段探索

1. 浅水码头：抓回海床上的船名牌。
2. 船钟还在响：安全长路与危险短路之间选路。
3. 唯一的一剪：打开捷径，或把唯一切网机会留给额外宝箱。

电量只随实际移动消耗。有限装载与返程成本决定取舍。普通船骸阻挡，红色残骸造成伤害。电量或耐久耗尽，本次收获不结算。暂停、切后台和恢复存档时不会继续扣电。

## 开发

- `npm run build`：生成浏览器与微信生产 bundle，无第三方运行时依赖。
- `npm test`：玩法与微信宿主契约回归。
- `src/core.js` / `levels.js`：确定性玩法。
- `src/render.js` / `app.js`：双端共享渲染与输入流程。
- `web.js` / `wechat/platform.js`：平台薄适配。

原始参考图由用户提供，局内对象独立绘制。音效为已有 CC0 音源，出处见 `assets/audio/SOURCES.md`，不是新合成音效。

## 验证边界

已跑确定性单元测试、无 DOM 的生产微信 bundle 宿主输入回归、原生 Canvas 生产渲染器静态像素检查。未声称浏览器实机试玩、微信开发者工具验收或微信真机验收；云沙箱阻止 Chromium 启动，云浏览器无法连接隔离的本地服务。当前是第一轮可玩性实验，不是完整发行版。
